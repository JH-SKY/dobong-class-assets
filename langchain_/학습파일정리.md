# AI Agent & RAG 학습파일 정리 

> 부족한 역량을 발견하면 해당 번호의 `.ipynb` 파일을 찾아 복습하세요.

---

### [ 요약]
* **01-04:** **[기초(Chain)]** LLM 소통법, 기억력(Memory), 출력 형식(JSON) 제어
* **05-06:** **[도구/모델]** AI에게 도구 쥐여주기(Tool), 내 컴퓨터에서 돌리기(Local)
* **07-10:** **[지식(RAG)]** 외부 데이터 공부시키기, DB 저장, 정확도 채점
* **11-13:** **[설계(Graph)]** 일의 순서도(Workflow) 그리기, 데이터 상태 관리
* **14-18:** **[고등에이전트]** 상황별 길 찾기(Router), 자기 반성(Reflection), 계획 실행(Plan-Execute)

---

## 1. [기초] LLM 통제 및 구조화 역량
**"AI라는 똑똑한 신입 사원과 제대로 소통하고 보고받는 법"**

* **01-02. 프롬프트 엔지니어링 (Prompting)**
    * **핵심:** AI에게 명확한 페르소나와 제약 사항을 부여하는 기술
    * **체크:** "내가 원하는 대로 AI가 대답을 안 하나?" → **01, 02번 복습**
* **03. 대화 메모리 (Memory)**
    * **핵심:** 이전 대화 맥락을 잃지 않게 관리하는 법
    * **체크:** "AI가 앞서 말한 조건을 자꾸 까먹나?" → **03번 복습**
* **04. 구조화된 출력 (Structured Output)**
    * **핵심:** JSON 형태로 답변을 받아 백엔드(DB)와 연결하는 필수 기술
    * **체크:** "AI 답변을 코드로 처리하기가 힘든가?" → **04번 복습**

---

## 2. [데이터] RAG 및 지식 확장 역량
**"AI에게 외부 교과서(DB)를 주고 검색해서 공부시키는 법"**

* **07-08. RAG 기초 & Vector DB**
    * **핵심:** 텍스트를 숫자(Embedding)로 바꿔 창고에 넣고 유사도로 찾는 원리
    * **체크:** "우리 회사/지원금 데이터 검색이 안 되나?" → **07, 08번 복습**
* **09. RAG 파이프라인 (Pipeline)**
    * **핵심:** 질문 → 검색 → 프롬프트 조합 → 생성의 전체 흐름 구축
    * **체크:** "검색부터 답변까지 과정이 매끄럽지 않나?" → **09번 복습**
* **10. RAG 평가 (Evaluation)**
    * **핵심:** AI가 가져온 정보가 진짜인지, 답변이 정확한지 수치로 채점
    * **체크:** "AI가 자꾸 헛소리(할루시네이션)를 하나?" → **10번 복습**

---

## 3. [실행] 에이전트 행동 역량
**"AI에게 도구(검색기/계산기)를 쥐여주고 직접 일시키는 법"**

* **05. Tool 호출 (Tool Agent)**
    * **핵심:** LLM이 스스로 판단해서 특정 함수나 API를 실행하는 기술
    * **체크:** "AI가 직접 DB 조회를 못 하고 말만 하나?" → **05번 복습**
* **12. ReAct 방식 (Reasoning + Acting)**
    * **핵심:** "생각하고(Reason) 행동하고(Act)"를 반복하며 답을 찾는 추론 기법
    * **체크:** "단순한 질문은 잘하는데 복잡한 추론을 못 하나?" → **12번 복습**
* **14. RAG Agent (지능형 검색)**
    * **핵심:** 무조건 검색하는 게 아니라, 필요할 때만 스스로 판단해서 검색하는 에이전트
    * **체크:** "검색이 필요 없는 질문에도 억지로 검색을 하나?" → **14번 복습**

---

## 4. [설계] 고등 워크플로우 (LangGraph)
**"복잡한 비즈니스 로직을 설계하고 예외 상황을 통제하는 법"**

* **11, 13. Graph 기초 & 상태 관리 (State)**
    * **핵심:** 일을 노드(Node)로 쪼개고 데이터(State)를 전달하는 설계 방식
    * **체크:** "전체적인 일의 순서(Workflow)가 꼬였나?" → **11, 13번 복습**
* **15. 가드레일 (Guardrails)**
    * **핵심:** 질문 난이도를 판별(Router)하거나 부적절한 답변을 차단하는 보안 기술
    * **체크:** "사용자 질문을 적절한 노드로 못 보내나?" → **15번 복습**
* **16. 자기 성찰 (Reflection)**
    * **핵심:** AI가 자기 답변을 스스로 검토하고 수정하게 만드는 기법
    * **체크:** "결과물의 퀄리티가 낮고 검수가 안 되나?" → **16번 복습**
* **18. 계획 기반 실행 (Plan-and-Execute) ★**
    * **핵심:** **[끝판왕]** 복잡한 미션을 받아 전체 계획을 짜고 순차적으로 실행/수정
    * **체크:** "정부 지원금 탐색 같은 초복잡 미션이 안 풀리나?" → **18번 복습**

###  학습 팁
1. **문제 발생:** `executor` 노드에서 자꾸 에러가 난다!
2. **원인 진단:** AI가 도구 사용법을 모르거나 프롬프트가 부실함.
3. **복습 지점:** **05번(Tool 호출)**과 **12번(ReAct)** 파일을 열어 코드를 다시 본다.
