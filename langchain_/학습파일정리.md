# AI Agent & RAG 학습파일 정리 

> 부족한 역량을 발견하면 해당 번호의 `.ipynb` 파일을 찾아 복습하세요.

---

### [ 요약 ]
* **01-04:** **[기초(Chain)]** LLM 소통법, 기억력(Memory), 출력 형식(JSON) 제어
* **05-06:** **[도구/모델]** AI에게 도구 쥐여주기(Tool), 내 컴퓨터에서 돌리기(Local)
* **07-10:** **[지식(RAG)]** 외부 데이터 공부시키기, DB 저장, 정확도 채점(검증)
* **11-13:** **[설계(Graph)]** 일의 순서도(Workflow) 그리기, 데이터 상태 관리
* **14-18:** **[고등에이전트]** 상황별 길 찾기(Router), 자기 반성(Reflection), 병렬 처리, 계획 실행(Plan-Execute)
* **19-20:** **[실무/협업]** 사람의 최종 승인(HITL), 여러 전문가 AI의 협동(Multi-Agent)

## 1. [기초] LLM 통제 및 구조화 역량
**"AI라는 똑똑한 신입 사원과 제대로 소통하고 보고받는 법"**

* **01-02. 프롬프트 엔지니어링 (Prompting)**
    * **핵심:** AI에게 명확한 역할과 제약 사항을 부여하는 기술
    * **체크:** "내가 원하는 대로 AI가 대답을 안 하나?" → **01, 02번 복습**
* **03. 대화 메모리 (Memory)**
    * **핵심:** 이전 대화 맥락을 잃지 않게 관리하는 법
    * **체크:** "AI가 앞서 말한 조건을 자꾸 까먹나?" → **03번 복습**
* **04. 구조화된 출력 (Structured Output)**
    * **핵심:** JSON 형태로 답변을 받아 백엔드(DB)와 연결하는 필수 기술
    * **체크:** "AI 답변을 코드로 처리하기가 힘든가?" → **04번 복습**

---

## 2. [데이터] RAG 및 지식 확장 역량
**"AI에게 외부 교과서(DB)를 주고 검색해서 공부시키는 법"**

* **07-08. RAG 기초 & Vector DB (임베딩 방법론)**
    * **핵심:** 텍스트를 숫자(Embedding)로 바꿔 창고에 넣고 유사도로 찾는 원리
    * **체크:** "우리 서비스 전용 데이터를 검색하게 하고 싶나?" → **07, 08번 복습**
* **09. RAG 파이프라인 (Pipeline)**
    * **핵심:** 질문 → 검색 → 프롬프트 조합 → 생성의 전체 흐름 구축
    * **체크:** "검색부터 답변까지 과정이 매끄럽지 않나?" → **09번 복습**
* **10. RAG 평가 (Evaluation / 검증 방법론)**
    * **핵심:** AI가 가져온 정보가 진짜인지, 답변이 정확한지 수치로 채점
    * **체크:** "AI가 자꾸 헛소리(할루시네이션)를 하나?" → **10번 복습**

---

## 3. [실행] 에이전트 행동 및 디자인 패턴
**"상황에 맞는 에이전트 설계 패턴(Design Pattern)을 적용하는 법"**

* **05. Tool 호출 (Tool Agent)**
    * **핵심:** LLM이 스스로 판단해서 특정 함수나 API를 실행하는 기술
    * **체크:** "AI가 직접 DB 조회를 못 하고 말만 하나?" → **05번 복습**
* **12. ReAct 방식 (Reasoning + Acting)**
    * **핵심:** [디자인 패턴] "생각하고 행동하고"를 반복하며 답을 찾는 추론 기법
    * **체크:** "단순한 질문은 잘하는데 복합적인 추론을 못 하나?" → **12번 복습**
* **15. 가드레일 & 라우팅 (Router)**
    * **핵심:** [디자인 패턴] 질문의 난이도나 성격에 따라 적절한 길로 보내는 기술
    * **체크:** "사용자 질문을 적절한 전문가 노드로 못 보내나?" → **15번 복습**
* **16-17. 자기 성찰(Reflection) 및 병렬화(Parallelization)**
    * **핵심:** AI가 스스로 검토하거나, 여러 일을 동시에 처리하게 만드는 기법
    * **체크:** "결과물의 품질이 낮거나 처리 속도가 너무 느린가?" → **16, 17번 복습**
* **18. 계획 기반 실행 (Plan-and-Execute) ★**
    * **핵심:** [끝판왕 패턴] 복잡한 미션을 받아 전체 계획을 짜고 순차적으로 실행
    * **체크:** "정부 지원금 탐색 같은 초복잡 미션이 안 풀리나?" → **18번 복습**

---

## 4. [고급] 실무 운영 및 협업 역량
**"AI의 실수를 방지하고 대규모 시스템으로 확장하는 법"**

* **19. 휴먼 인 더 루프 (Human-in-the-loop / HITL)**
    * **핵심:** 중요 시점에서 AI 동작을 멈추고 사람의 승인을 받는 안전장치
    * **체크:** "AI가 멋대로 지원금을 신청하면 어떡하지? 내 확인이 필요한데?" → **19번 복습**
* **20. 멀티 에이전트 (Multi-Agent)**
    * **핵심:** 전문가 AI(검색광, 작성광 등)들을 팀으로 묶어 협업시키는 구조
    * **체크:** "한 명의 AI에게 너무 많은 일을 시켜서 과부하가 걸리나?" → **20번 복습**
